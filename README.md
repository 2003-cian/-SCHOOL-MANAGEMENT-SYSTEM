School Management System

A simple web-based school management system built with Flask that allows administrators to manage students, teachers, courses, attendance, and grades.

## Features

- Dashboard with overview statistics
- Student management (add, view, edit, delete)
- Teacher management (add, view, edit, delete)
- Course management
- Attendance tracking
- Grade management
- Reports and analytics
- Responsive design for all devices

## Technology Stack

- Backend: Flask (Python)
- Frontend: HTML5, CSS3, JavaScript, Bootstrap 5
- Database: SQLite (can be configured to use PostgreSQL)
- Deployment: Render
